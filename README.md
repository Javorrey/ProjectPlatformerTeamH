Bienvenido a Artemis 67!!

Este es un juego donde se controla a un astronauta de la expedición Artemis 67 para encontrar los horrores de marte y escapar del planeta.

Para ejecutar el juego:

- Se tiene que tener Python 3 instalado
- Se debe instalar la libreria Arcade en la terminal con: pip install arcade o python3 -m pip install arcade
- Se debe entrar a la carpeta src escribiendo en la terminal cd src
- Para ejecutar el juego, se escribe python main.py

Controles del juego:

- W,S (o ^, v) para apuntar hacia arriba y abajo respectivamente.
- A,D (o <, >) para caminar hacia la izquierda y derecha respectivamente.
- [Space] para saltar.
- [LMB] para disparar.
- [RMB] para expulsar bomba. Se vera un rayo amarillo en la esquina de abajo del juego que indicara si la bomba esta lista. Si se encuentra en rojo, estará en recarga. También, al ponerlo debajo de tus pies, se podra usar para impulsarse hacia arriba.

Si se necesita consultar otra vez, en el menú en la esquina superior derecha se puede presionar el icono del mando para ver las instruccióbes de nuevo.

En el menú, se encontrarán cinco botones:
- El botón "Jugar" se utiliza para entrar al nivel seleccionado.
- El botón "Nivel" se utiliza para seleccionar el nivel querido.
- El botón "Ajustes" se ultiliza para poder ajustar el volumen del juego además de seleccionar si se quiere poner en pantalla completa.
- El botón "Salir" se utiliza para salir del juego.
- El botón con forma de mando en la esquina superior derecha, como mencionado antes, se utilizará para poder ver los controles del juego.
